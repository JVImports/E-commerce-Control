# Deploy legado

Arquivos históricos do antigo fluxo de deploy direto da função `shopee-sync`.

Este procedimento não é o fluxo vigente: o wrapper local `supabase.exe` estava quebrado e foi removido. O projeto atualmente usa as funções versionadas em `supabase/functions/` e o Supabase MCP para operações remotas.

Não executar estes arquivos sem antes revisar destinos, autenticação e compatibilidade com o ambiente atual.
